BandPlacer scenarios
====================

A BandPlacer session produces a lot short touches, some of which might
fire out, so it's probably best used somewhere with tolerant
neighbours, or a simulator.

It's probably useful to discuss each touch immediately afterwards, and
to make the most of available rope time, it would be useful to do this
outside the ringing room, while another band is ringing their next
touch; so a ground floor ring, or an upstairs one with an adjoining
space, would be ideal.

Simple use
----------

For simple use, BandPlacer can be used from the command line, with the
ringers registering by putting their names and method choices into a
CSV file (spreadsheet).  The placement file for the band for each
touch can be viewed in a spreadsheet program or text editor, and the
score entered through the same program.

Advanced use
------------

**This is not yet implemented, and is mentioned to show the direction
  the software is intended to develop.**

BandPlacer can be run on a server, with a web UI that allows people to
register and declare their method choices through web forms.

While the session is running, the next band can be displayed on a
monitor screen in the tower, and the scoring partly automated through
an interface to HawkEar, with confirmation and intervention through a
web form.
